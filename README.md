# 뷰티오라(BEAUTYORA) 브랜드 랜딩페이지

뷰티오라 B2B 랜딩페이지 저장소입니다. 입점을 검토하는 브랜드 담당자에게 뷰티오라를 소개하고, 입점 제안(구글 폼)과 메일 상담으로 이어지게 하는 것이 이 페이지의 목적입니다.

- 운영 주소: https://beautyora.kr
- 호스팅: Netlify 프로젝트 `beautyora`. GitHub `main` 브랜치에 푸시하면 자동으로 운영 사이트에 배포됩니다.
- 기준 자료: [뷰티오라 회사 소개서 (노션)](https://hypnotic-nitrogen-625.notion.site/3d81223f7bc180d2822beb2a00aeb78e), `뷰티오라_B2B_소개서_260916_03`, 22쪽

## 폴더 구조

```
docs/image-prompts.md 이미지 생성 프롬프트와 아이콘 목록
dist/                 ← Netlify가 배포하는 폴더 (빌드 과정 없는 정적 사이트)
├── index.html        페이지 구조와 문구
├── site.css          디자인 (색·글꼴·레이아웃·모션)
├── site.js           인터랙션 (스크롤 연출, FAQ, 입점 폼 링크 등)
└── assets/
    ├── hero-stage.webp 히어로 전면 이미지
    ├── hero.webp     예전 히어로 이미지 (마케팅비 섹션에서 사용)
    ├── ch-*.webp     입점처 카드 사진 (생성 예시 이미지)
    ├── mk-*.webp     마케팅 타일 사진 (생성 예시 이미지)
    ├── ex-*.webp     경험 4단계 카드 사진 (생성 예시 이미지)
    ├── logo.svg      워드마크
    └── symbol.svg    심볼 (파비콘, 마스크 이미지)
.openai/hosting.json  예전 ChatGPT Sites 배포 설정 (현재 운영과 관계없음)
```

로컬에서 확인하려면 다음 명령을 실행한 뒤 http://localhost:8000 에 접속합니다.

```bash
python3 -m http.server 8000 -d dist
```

## 디자인 원칙

`dist/site.css` 맨 위의 원칙을 그대로 따릅니다.

- **색:** 화이트, 연노랑(`#F1EB9D`), 그레이 세 가지 계열만 씁니다. 검정 면은 쓰지 않습니다.
- **글꼴:** 제목·본문·영문·숫자 모두 Pretendard 하나로 씁니다. (2026-09-23 요청으로 Panchang 제거)
- **장식:** 괘선과 작은 영문 라벨은 쓰지 않습니다. 구분은 면 색과 여백으로 합니다.
- **아이콘:** Google Material Symbols(Rounded · 굵기 300)만 씁니다. SVG로 페이지에 직접 넣고, `data-icon`에 이름을 적어 둡니다.
- **모션:** `prefers-reduced-motion`(모션 줄이기) 설정을 켠 사용자에게는 모든 연출을 끄고, 내용이 처음부터 보이게 합니다.

- **모바일:** 세로 화면에서는 사진을 채워 쓰고, 제목 아래로 크림 용기와 받침대가 보이도록 위치를 맞췄습니다.

### 2026-09-23 · 전면 히어로 완성

**요청 내용**

> 이대로 완성 해주세요

**의도:** 앞에서 제안한 전면 히어로(사진 한 장이 첫 화면을 가득 채우는 방식)를 실제 페이지에 적용합니다.

**반영 내용**

- **레이아웃:** 히어로가 화면 높이 전체를 채우고, 사진이 배경 전체에 깔립니다. 헤더는 사진 위에 투명하게 올라가고, 스크롤하면 기존처럼 흰 배경으로 바뀝니다.
- **글 가독성:** 제목 쪽(데스크톱 왼쪽, 모바일 위쪽)에 옅은 흰 막을, 아래쪽에 연노랑 빛을 깔았습니다. 어떤 사진으로 바꿔도 제목이 읽힙니다.
- **연출:** 처음 열릴 때 사진이 살짝 확대된 상태에서 2.6초 동안 천천히 제자리로 돌아옵니다. 스크롤하면 사진이 조금씩 커지고 흐려지며, 제목은 위로 떠나면서 사라집니다. 심볼 선이 그려지는 연출은 사진 위에 옅게 남겼습니다. 화면 아래에는 스크롤을 안내하는 작은 표시를 두었습니다.
- **모바일:** 제목은 위쪽, 사진의 주인공(크림 용기)은 아래쪽에 보이도록 사진 위치를 따로 잡았습니다.
- **모션 줄이기 설정:** 확대·흐림·안내 표시 움직임을 모두 끕니다.
- **사진:** 콘셉트 A(무대) 이미지는 아직 없어서, 기존 히어로 사진(`assets/hero.webp`)으로 먼저 완성했습니다. 새 사진이 오면 `index.html`의 `#heroimg` 파일만 바꾸면 됩니다. 모바일용 세로 사진을 따로 받으면 화면 폭에 따라 사진을 골라 쓰도록 연결합니다.

- **메일 상담:** "메일 보내기" 버튼을 지우고 "주소 복사" 하나만 남겼습니다. 남은 버튼은 눈에 잘 띄도록 진한 버튼으로 바꿨습니다.
